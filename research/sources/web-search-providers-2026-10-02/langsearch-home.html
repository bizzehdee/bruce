A FEW GOOD QUESTIONS

Clear answers.
No fine print.

Is the Web Search API really free?+

Yes. Web Search and its supported features are free, including snippets, full webpage text, date and domain filtering, and up to 50 results per request.

What’s included in the Free Plan?+

A daily token allowance with all supported Web Search features included. Input and output token prices are currently $0. Your daily allowance resets at 00:00 UTC.

Is there a usage limit?+

Yes. New accounts start at 5 RPS; existing accounts retain their configured request rate. Usage is measured in tokens, with limits per minute (TPM) and per day (TPD). All your Web Search API keys and MCP calls share the same allowance. Your dashboard shows tokens used, the percentage consumed, and the next daily reset.

How is token usage measured?+

Each successful search counts the query as input tokens and returned search content as output tokens. Titles, URLs and other metadata are excluded. The API reports input_tokens and output_tokens in usage. Longer returned content consumes more of your token allowance.

Does full webpage text cost extra?+

No. Set contents.text to true to receive text instead of snippet, with a default limit of 5000 characters per result. Use contents.text: { "max_characters": 3000 } to choose a different positive limit. Available source text may be shorter. There is no extra feature fee, but the returned text counts toward your token allowance.

Can I choose dates and domains?+

Yes. Use freshness with a preset, a specific date (YYYY-MM-DD), or an inclusive date range (YYYY-MM-DD..YYYY-MM-DD). Use includeDomains and excludeDomains to focus on the sources you need.

Can I use this with an AI agent?+

Yes. Call the Web Search API from your agent’s tools and pass the returned context and source URLs to your model. You can also connect through MCP or add the LangSearch Skill to your agent workflow.

How are the prices compared?+

We use published USD usage rates, dated September 13, 2026. Free credits and plan discounts can reduce other providers’ bills. Separate research, extraction and answer products are identified and are not presented as equivalent LangSearch features.
